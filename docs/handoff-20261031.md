## 2. สถานะความปลอดภัยและการปกป้องหน้าแรก (Protected Design)

- **หน้าแรก (`/`):** ยึดหลัก **ห้ามแตะต้อง (Protected Design)** ตามข้อตกลงกับผู้ใช้อย่างเคร่งครัด การปรับปรุง UX/UI ทั้งหมดถูกจำกัดขอบเขตเฉพาะส่วนหลังบ้าน (`/admin`) และฟอร์มแจ้งเรื่อง (`/intake`) เท่านั้น ไม่มีการแก้ไข Global CSS, Tokens, Root Layout หรือ Landing Primitives ใด ๆ
- **Local Verification Gates:**
  ```bash
  npx tsc --noEmit                          # 0 errors
  npx eslint .                              # 0 errors, 0 warnings
  npx vitest run                            # 131 test files, 1147+ tests ผ่านทั้งหมด
  npx tsx scripts/check-contrast.ts         # 100% WCAG contrast ผ่านทั้ง light/dark
  ```

## 3. สถานะการเทียบเคียงและรออัปเดตจาก `jsk-app`

ปัจจุบันระบบรับเรื่องร้องเรียน อบต.หัวงัว ได้พอร์ตฟีเจอร์หลักจาก `jsk-app` (`D:\genAI\jsk-app`) มาครบถ้วนแล้ว:

## 5. กติกาและข้อบังคับสำหรับผู้พัฒนา/เอเจนต์รอบถัดไป

1. **ห้ามใช้ `pnpm`:** ให้ใช้ `npx` ในการรันคำสั่งเสมอ (เช่น `npx vitest run`, `npx tsc --noEmit`) เนื่องจากสภาพแวดล้อมนี้มีปัญหา `pnpm` แฮงค์
2. **ห้ามแก้หน้าแรก (`/`):** ยึด Landing page เดิมตาม `docs/uxui-handoff.md` §2 ห้ามแก้ไฟล์ร่วมที่ส่งผลกระทบต่อหน้าแรก
3. **Branch First:** สร้าง branch ใหม่จาก `main` เสมอ ห้าม commit บน `main` โดยตรง
4. **ภาษาไทย & สัญลักษณ์ `§`:** ข้อความสำหรับผู้ใช้และคอมเมนต์อธิบายโค้ดให้ใช้ภาษาไทย โดยใช้เครื่องหมาย `§` นำหน้าคอมเมนต์ที่อธิบายเหตุผลหรือเบื้องหลังเชิงเทคนิค
